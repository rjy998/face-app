- 眉长且全部朝下者，传统说法认为需留意感情分寸；部分朝下者，传统说法认为较适合学文。
- 眉短者，传统说法认为财运与婚姻需多留意，感情易受外界干扰；特长者较为理智。
- 双层眉者，传统说法认为与母亲经历相关，包括随母改嫁、母亲在两地怀孕或母亲为父亲侧室。
- 眉断、眉散者，传统说法认为财易散；眉中断者，传统说法认为兄弟不合、与夫妻感情差，也代表与兄弟缘分较薄。
- 眉下垂者，传统说法认为好色且依赖性较重。
- 左眉断者，传统说法对应 3 数。
- 眉炸（散开）者，传统说法认为父母易有争执；眉往上翻者，情绪易不稳定。
- 眉有势者，传统说法认为事业有高峰期。
- 切眉者，传统说法认为在申、巳年运气欠佳，申、巳月同样不吉。
- 眉压眼者，传统说法认为较为暴戾，若再无颧相配合，男性在世易居低位。
- 眉一高一低（一长一短）者，传统说法认为感情方面易有波折、性格有双重性、与兄弟姐妹关系复杂。
- 眉锁印者，传统说法认为运势受阻，宜修眉以开阔。
- 眉过宽者，传统说法认为性易放荡、易受骗。
- 靠眉上有痣者，传统说法认为易被盗；眉为围墙，有斑纹、发青时也易有此风险。
- 眉向上者，传统说法认为离家早、果敢倔强，较为适合纪律性环境。
